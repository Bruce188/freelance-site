# Freelance site

Static bilingual one-page site (Dutch default at `/`, English at `/en/`). Plain HTML/CSS, no build step.

## Before publishing
Replace `EMAIL_PLACEHOLDER@example.com` in `index.html` and `en/index.html` with your real address.

## GitHub Pages
Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
